🖥️ Frontend — dashboard.html Vanilla JS
Single-page app served by Flask. No bundler — pure HTML/CSS/JS.
Index ticker (LTP, OHLC, prev-close) — auto-refreshes every 5s
Option chain table with ITM highlight + 🛒 Buy button
Claude AI chain analysis — per-strike & full chain summary
S/R Overview panel — nearest support/resistance for all 4 indices
Monitor config cards — S/R Proximity, Market Update, Breach Monitor
Lightweight Charts candlestick chart with S/R overlays
Inline alert logs (S/R, Market Update, Breach) per card

Live feed + historical data from 5paisa. All routes require auth.

Python Modules — modules/
📊 market.py Data
All market data fetching from 5paisa SDK.
get_index_ltp() — live feed + prev-close
_fetch_prev_day_close() — walks last 12 days, skips today
get_today_ohlc() — intraday chart
get_option_chain_data() — all strikes
get_chart_data() — multi-day candles
⏰ scheduler.py Jobs
APScheduler background jobs running server-side.
sensex_snapshot
Every 1 min — saves chain snapshot silently to DB
sr_monitor
Configurable freq — checks LTP vs saved S/R levels, Telegram alert if within threshold%
market_update
Configurable freq — sends multi-index LTP/change summary to Telegram
breach_monitor
Configurable freq — detects S/R level breaches, saves + Telegram alert

External Services
📡 5paisa API Broker
Official py5paisa SDK. Authenticated per-session with OAuth JWT.
fetch_market_feed() — live LTP via WebSocket feed
historical_data() — OHLCV candles (1d, 15m, 4h…)
get_expiry() — option expiry dates
option_chain() — full chain CE+PE data
place_order() — limit intraday buy order
Scrip code split: feed_scrip (live) vs chart_scrip (historical)
🤖 Anthropic API AI
Claude AI for market analysis. API key via ANTHROPIC_API_KEY in .env.
Model: claude-haiku-4-5 (fast & cost-efficient)
Option chain summary — PCR, max pain, bias, watch levels
Per-strike CE/PE 15m candle analysis
S/R level detection from 1-year daily OHLC — returns JSON
Scheduler jobs use Claude for Telegram market summaries
📱 Telegram Bot Alerts
Push notifications to a Telegram chat. No user interaction — outbound only.
S/R proximity alert — "NIFTY within 0.25% of resistance 25000"
Level breach alert — "SENSEX breached support 75000 ↓"
Market update — multi-index LTP / change / AI summary
Dedup: was_recently_alerted() blocks repeat alerts within 30 min
